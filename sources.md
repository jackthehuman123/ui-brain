# Trusted sources (ranked)

Use the highest tier that answers the question. Cite in the note's `sources:` frontmatter.

## Tier 1: Platform guidelines
- Apple Human Interface Guidelines: https://developer.apple.com/design/human-interface-guidelines/
- Apple WWDC design and animation sessions: https://developer.apple.com/videos/
- Material Design 3: https://m3.material.io/ (machine-readable tokens: `material-components-android` tokens.xml)
- Android Developers (Compose): https://developer.android.com/develop/ui/compose
- Microsoft Fluent 2: https://fluent2.microsoft.design/
- Roblox Creator Docs: https://create.roblox.com/docs
- Unity Manual / TextMeshPro / UI Toolkit docs: https://docs.unity3d.com/

## Tier 2: Specs and references
- WCAG 2.2 and Understanding docs: https://www.w3.org/WAI/WCAG22/Understanding/
- CSSWG drafts: https://drafts.csswg.org/
- MDN Web Docs: https://developer.mozilla.org/
- web.dev (Core Web Vitals, etc.): https://web.dev/

## Tier 3: Recognized practitioners
- Björn Ottosson, Oklab: https://bottosson.github.io/posts/oklab/
- Evil Martians (OKLCH, color tooling): https://evilmartians.com/chronicles
- Butterick's Practical Typography: https://practicaltypography.com/
- Rasmus Andersson / Inter (dynamic metrics): https://rsms.me/inter/
- Nielsen Norman Group: https://www.nngroup.com/

## Not acceptable as the only source
AI-generated skill or summary sites, SEO listicles, Medium posts without primary citations, and forum answers. A DevForum post from Roblox staff is acceptable when Roblox docs say nothing; say so in the note.
